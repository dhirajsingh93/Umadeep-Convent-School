# 🏫 Umadeep Convent School

A modern, responsive and SEO-friendly official school website designed for **Umadeep Convent School, Ballabhgarh, Faridabad, Haryana**.

The website provides students and parents with easy access to school information, admissions, academics, faculty, gallery, contact details and other important resources.

## 🌐 Live Website

🔗 https://umadeepconventschool.com/

- 📱 Fully Responsive Design
- 🎓 School Information & Academics
- 📝 Admission Information

- 📸 School Gallery
